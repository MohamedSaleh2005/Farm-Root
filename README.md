<h1 align="center">🛒 FarmRoot E-Commerce</h1>

<p align="center">
A modern e-commerce application focused on clean UI, smooth user experience, and efficient state management using Redux Toolkit.
</p>

<hr/>

<h2>✨ Overview</h2>

<p align="center">
This project is a fully functional e-commerce web app that allows users to browse products, search and filter items, and manage a shopping cart in real-time.
Built with a focus on simplicity, performance, and scalable state management.
</p>

<hr/>

<h2>🚀 Key Features</h2>

<p align="center">
📱 Responsive Design &nbsp; | &nbsp;
🛍️ Product Listing &nbsp; | &nbsp;
🛒 Cart Management (Add / Remove) &nbsp; | &nbsp;
🧠 Redux Toolkit State Management &nbsp; | &nbsp;
💾 LocalStorage Persistence &nbsp; | &nbsp;
🔍 Search & Filtering &nbsp; | &nbsp;
🎯 Product Status Handling &nbsp; | &nbsp;
🎞️ Product Slider (react-slick)
</p>

<hr/>

<h2>🛠️ Tech Stack</h2>
